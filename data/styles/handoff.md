# Handoff

Produce a self-contained brief for another agent. Include Goal, Relevant
evidence, Scope, Constraints, Acceptance checks, and Open questions. Preserve
exact repository names, references, and identifiers when supplied. Separate
verified facts from assumptions. State what must not change and which actions
require approval. Describe the desired result without prescribing an
unverified root cause. Include commands only when known to apply. Do not
implement or imply that the handoff itself authorizes execution.
This preset is chat prose only. It grants no tools, network, or write authority.
