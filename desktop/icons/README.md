# desktop/icons

App icon sources. Regenerate with [scripts/desktop-icon.swift](../../scripts/desktop-icon.swift).

- [`icon.icns`](icon.icns): the shipped icon set, copied into the `.app` by `package-desktop.sh`.
- [`icon.png`](icon.png): the 2048px master (over 1 MiB, listed in the guard's `LARGE_FILES`).
- [`lol-im-a-fool-swift-vectorizes-the-image--OG-icon.png`](lol-im-a-fool-swift-vectorizes-the-image--OG-icon.png):
  the 512px original raster the Swift script was drawn from; referenced nowhere, not shipped.
