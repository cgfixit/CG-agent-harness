Local account and HTTPS
Fresh homes require account login over HTTPS. Sign in as admin with the one-time setup code shown above, then replace it immediately with at least 12 characters; this window stays open until then. From the console window, Cmd and + (Cmd, Shift and =) reopens it. Existing homes preserve their explicit configuration.


The native console verifies the exact certificate from its owned backend. No system trust installation is needed. If the certificate expires, quit this home's server and use the bundled CLI's tls renew command; operator-supplied certificates require operator renewal.


External browsers need a separate trust decision, including private windows. Export only this public certificate and compare its SHA-256 fingerprint before trusting it:
Safari and Chrome/Chromium on macOS: import the exported certificate into your login keychain, then review its SSL trust in Keychain Access. Firefox can require its own certificate exception or a browser-trusted operator certificate. Keep certificate checks enabled. Trust belongs to this home’s certificate; renewal or a new home needs a new review.


Provider credentials are optional. After login, administrators can save, replace or clear them in API Keys. They take effect after restart; explicit process environment values override the saved file. A harness metadata key never grants account access.


Coding prerequisites
Ordinary app startup needs no Rust or Xcode installation. Coding checks require the selected toolchain and prepared Cargo sources. Select a repository to prepare it using the bundled Python 3 helper. This action is offline and never downloads dependencies.




Recovery and local models
If Ollama is unavailable, start your installed Ollama app and retry. Select an exact installed model in the console with /model list and /model use. Chat and planner settings are separate; this app does not install or switch model runtimes.


Close hides the window; Dock reopens it. Cmd-Q quits with a cancellation choice when work is active. A crash may leave interrupted work: inspect retained jobs and run diffs before starting another run. No approvals, commits, pushes or publications are replayed.
