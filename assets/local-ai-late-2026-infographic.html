01 · Holistic overview

Local went from hobby to default

Detailed summary

Three forces converged this year. First, open-weight models in the 27-billion-parameter dense class now post agentic coding scores that would have looked like frontier results a year ago, and they fit in roughly 18 GB at 4-bit precision, which turns a single 24 GB workstation card into a legitimate AI server. Second, hardware vendors stopped competing on NPU TOPS and started competing on memory: AMD's Strix Halo (128 GB), its Gorgon Halo successor (192 GB), Apple's M5 Max (128 GB at up to 614 GB/s), Qualcomm's X2 Elite and Nvidia's DGX Spark all pool CPU and GPU memory so bigger models simply fit. Third, the software stack matured to weekly cadence: llama.cpp shipped FP8 E4M3 quantization and a unified KV cache on 4 November, and Ollama added Liquid AI's LFM3 agent models and Xiaomi's 9B MiMo V2.6 days later.

The uncomfortable half of the story is exposure. A year-long Nankai University study accepted at ACM IMC 2026 counted 152,137 cumulative IPs serving Ollama's unauthenticated API to the public internet, with only 0.43–2.90% of vulnerable hosts upgrading in place. A separate January 2026 scan put the figure at 175,000 hosts in 130 countries, 48% advertising tool calling. In June 2026 Sysdig watched an attacker use one such box as the reasoning engine for an 8.5-hour autonomous exploitation run. No vulnerability was needed; the port was open.

The mature pattern for 2027 is hybrid by design: local for volume, privacy and iteration; cloud for peak reasoning; and a harness around the local agent that treats tool calling, MCP servers and model files as a supply chain. This page gives you the hardware ladder, a model-fit calculator, the current stack, the exposure numbers, seven things to watch, and a checklist you can run today.

02 · Hardware

Capacity decides what fits. Bandwidth decides how fast.

PCMag's new AI-PC test methodology formalizes what practitioners already knew: there are three classes of local AI machine, and the dividing line is memory, not marketing TOPS.

CLASS 1 / EVERYDAY NPU PC

≥16 GB RAM, NPU or light GPU

Runs small language models for summarizing, live captions, translation and webcam effects. The Copilot+ bar is a 40+ TOPS NPU.

  • Qualcomm X2 Elite: 80 TOPS (85 on Extreme)
  • Intel Panther Lake: NPU 5, up to 50 TOPS
  • AMD XDNA2 (Strix Halo NPU alone): 50 TOPS
CLASS 2 / GAMING OR WORKSTATION GPU

≥32 GB RAM + ≥16 GB VRAM

Discrete VRAM is still the fastest per-token path by a wide margin if the model fits. Medium LLMs and agents live here.

  • 27B coding model on a single RTX 3090 at usable speed
  • 24 GB card ≈ a serious single-user AI server
  • Limits: VRAM ceiling, power, cooling
CLASS 3 / UNIFIED MEMORY

≥96 GB unified memory or aggregate VRAM

CPU, GPU and NPU share one high-bandwidth pool. Originally sold to developers; now the baseline for running the largest local models and overnight agent loops.

  • Nvidia DGX Spark / RTX Spark laptops: up to 128 GB (64 GB variants now shipping)
  • Apple MacBook Pro: 48 / 64 / 128 GB configurations
  • AMD Ryzen AI 400 boxes expected in similar tiers

Vendor-published or independently reported figures. Gorgon Halo's 273 GB/s is a 7% bump over Strix Halo; expect similar 4–5 tok/s on 70B dense models, just with room for larger MoE models to fit. Bandwidth, not TOPS, governs generation speed once a model fits.

04 · Reality check

Your local model may not be local

Ollama binds to 127.0.0.1 by default and ships no authentication of any kind. Exposure is therefore a deployment decision, not a vulnerability, which is exactly why version-keyed scanners report exposed boxes as clean.

June 2026: a victim's GPU wrote the exploits

Sysdig observed an attacker use an exposed Ollama server as the reasoning engine for an autonomous exploitation framework: an 8.5-hour session fingerprinting targets and writing working exploits through privilege escalation, returning two days later from three residential IPs. No CVE was exploited.

Writes are unauthenticated too

/api/create, /api/pull, /api/push and /api/delete sit on the same port. LLMjacking scripts have been seen calling /api/create to register models on exposed servers.

Pre-authenticated CVEs

CVE-2024-37032 (unauthenticated root RCE on Docker installs, public Metasploit module) and CVE-2026-7482 (May 2026, remote process-memory read that can expose prompts and API keys). Open WebUI carries its own cluster, including a May 2026 code-execution flaw that ran even with code execution disabled.

Three controls that do not do what you think

OLLAMA_ORIGINS is a browser CORS list that curl ignores. A ufw deny rule never sees Docker-published traffic because it is diverted in the nat table first. Proxy auth on 443 means nothing while 11434 is published beside it.

Model files are a supply chain

Security researchers documented Hugging Face and ClawHub being abused for malware distribution in spring 2026. OWASP's Agentic Top 10 (ASI04) now explicitly covers malicious tools, MCP servers, agent cards and registries.

Safety-stripped templates in the wild

The January 2026 scan found at least 201 exposed hosts running prompt templates with safety instructions removed, 56% of them on fixed-line telecom networks rather than cloud hosting, meaning home and small-office boxes, not just rented VMs.

Verification beats assumption: from a machine on a different network run nmap -Pn -p 11434 your.host then curl -s -m 5 http://your.host:11434/api/tags. Read the response body, not just the exit code.
05 · Futurism

Seven things to watch into 2027

Each item is grounded in something that shipped or was measured this year, then extended one honest step. Filter by lane.

Hardware

Capacity keeps jumping; bandwidth creeps

Strix Halo 128 GB → Gorgon Halo 192 GB is a 50% capacity jump with only 7% more bandwidth. AMD's LPDDR6 "Medusa Halo" (leaked ~460 GB/s) is a 2027–2028 story.

Expect MoE models to be the winners on x86 unified memory: they need capacity more than bandwidth. Dense 70B stays slow until LPDDR6.
Hardware

DRAM prices stay high because of you

PCMag notes AI-driven demand keeps DRAM prices unusually high, which is why vendors sell 24/32/64 GB tiers of "Class 3" machines.

Buy the memory tier, not the chip. A 64 GB Spark or Mac is a different product class from the 128 GB version.
Software

Lower precision becomes the norm

FP8 E4M3 is now native in llama.cpp; Apple ships 2-bit on-device models; distillation and flash-based weight loading are named as core SLM trends.

Benchmark your own tasks at each quant level; "fits" and "still passes my eval" are different claims.
Software

Architecture churn outruns engine support

New hybrid-attention and state-space releases often cannot load in stock llama.cpp, LM Studio or Ollama until a specific PR merges.

Track the engine PR, not the model card. Keep one stable engine pinned for production and one bleeding-edge build for evaluation.
Security

Local agents inherit the full OWASP ASI list

Tool calling on 48% of exposed hosts plus unauthenticated model writes means goal hijacking, tool misuse, memory poisoning and supply-chain risks apply at home, not just in enterprises.

A harness with staged authority around a local model is not over-engineering; it is the minimum once the model can call tools.
Security

Provider-level mitigation is coming

The Nankai authors note cloud and hosting ASNs dominate exposure and flag "the potential reach of provider-level mitigation."

Expect cloud providers to start blocking or warning on public 11434. Do not wait for them; the 56% on telecom networks will not be covered.
Market

Fixed cost, free marginal run

Local inference flips the cost shape: hardware is a fixed cost and each run is free, so teams let agents attempt fifty refactors overnight and keep the best one.

Design workflows that exploit free retries (best-of-N, overnight loops) instead of porting per-token habits from the cloud.

07 · Wild card

The $15 language model

Buried in this week's local-inference roundups is a detail that reframes the whole hardware conversation: Andrej Karpathy's training recipes now let someone train a small ChatGPT-style model from scratch for roughly $15 to $100 in compute. The point is not that the result rivals a frontier model; it does not. The point is that the barrier to understanding how these systems work, end to end, has collapsed to the price of a dinner. In 1975 the Altair-era hobbyist had to build the machine to learn the machine. In 2026 the equivalent rite of passage is training a toy model, watching the loss curve, and then loading a real open-weight checkpoint into your own memory pool. The second step is where the moat is; the first step is where the understanding is.
