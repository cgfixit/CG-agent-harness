# docs

Operator and contributor guides, one topic per file. Start from the table in
the root [README.md](../README.md#documentation). Agents open a file here only
when a root file links it and the task needs it; `learning/` is never read
unless the operator asks. Every file has a word cap in `tests/invariant_guard.rs`
(`DOCS_BUDGET`); edit the owning section rather than adding files, and delete
every link when a file goes. Screenshots live in `screenshots/`.
